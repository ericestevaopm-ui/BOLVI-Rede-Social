# Bolvi

**Connect. Share. Belong.**

Bolvi is a social networking platform designed to bring people together, build connections, and create meaningful interactions in a connected digital environment.

## Features

- User registration and authentication
- Personalized user profiles
- Friend requests and connections
- Social search
- Personal profile walls
- Interactive posts and messages
- Poke functionality
- Real-time-style notifications
- Persistent SQLite database
- Secure session management
- Responsive user interface

## Technology Stack

- **Backend:** Node.js, TypeScript, Express
- **Database:** SQLite, better-sqlite3
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Templates:** EJS
- **Security:** bcrypt, Helmet, CSRF protection, rate limiting
- **Testing:** Vitest, Supertest

## Project Status

Under active development.
